# ammora-launchpad
A simple launchpad and exchange on GIWA Sepolia, built using the Ammora SDK.

## Features

- Wallet connection
- Token creation via Config
- List of recent launches
- Buying and selling via a bonding curve (ALC)
- Automatic token approval for sales

## Getting Started

```bash
npm install
npm run dev
```

Important:
Network: GIWA Sepolia (91342)
Do not use Config #6
Testnet only
Created for the Ammora Builder Mission.
